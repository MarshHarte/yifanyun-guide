## 从安装到第一条可用连接

一翻云的指南以首次接入为主线：确认账户、选择系统、获取当前接入方式，再检查目标应用。每一步都有明确的完成条件，方便新设备从头配置。

### 1. 先确认账号状态

进入账户后确认套餐已生效、流量可用。仅注册成功不等于已经具备可用订阅。

### 2. 找到对应系统教程

按 Windows、macOS、Android 或 iOS 查阅安装说明，确认当前是否提供专用客户端及其他接入方式。

### 3. 完成应用层验证

连接后打开真正要使用的网站或应用，检查登录与内容加载，不以客户端出现已连接就结束检查。

## 使用体验如何检查

把地区、运营商、时段、客户端版本和目标应用保持一致，再比较连接结果。持续访问、下载峰值和应用地区识别是不同指标；失败或超时也应记录。本文未发布本次实测速度或实时节点状态。

可在自己的设备上记录以下信息，向账户支持反馈时隐藏个人凭据：

| 记录项 | 填写方式 |

| 设备与网络 | 系统、客户端版本、运营商及 Wi-Fi／移动数据 |

## 一翻云常见问题

### 一翻云登录成功后还需要做什么？

确认订阅状态，按系统教程配置客户端，再检查目标应用的实际访问。

### 客户端导入栏应该填写哪个地址？

只填写账户提供的对应格式订阅；本页四个链接用于访问网站，不是个人订阅。

### 当前套餐价格与活动在哪里确认？

进入账户查看当前订单，核对实付金额、付款周期、流量重置、有效期、设备限制与售后条件。历史截图和旧优惠码不能代替当前交易条款。
