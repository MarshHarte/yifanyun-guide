## 從安裝到第一條可用連線

一翻雲的指南以首次接入為主線：確認賬戶、選擇系統、獲取當前接入方式，再檢查目標應用。每一步都有明確的完成條件，方便新裝置從頭配置。

### 1. 先確認賬號狀態

進入賬戶後確認套餐已生效、流量可用。僅註冊成功不等於已經具備可用訂閱。

### 2. 找到對應系統教程

按 Windows、macOS、Android 或 iOS 查閱安裝說明，確認當前是否提供專用客戶端及其他接入方式。

### 3. 完成應用層驗證

連線後開啟真正要使用的網站或應用，檢查登入與內容載入，不以客戶端出現已連線就結束檢查。

## 使用體驗如何檢查

把地區、運營商、時段、客戶端版本和目標應用保持一致，再比較連線結果。持續訪問、下載峰值和應用地區識別是不同指標；失敗或超時也應記錄。本文未釋出本次實測速度或實時節點狀態。

可在自己的裝置上記錄以下資訊，向賬戶支援反饋時隱藏個人憑據：

| 記錄項 | 填寫方式 |
| --- | --- |
| 裝置與網路 | 系統、客戶端版本、運營商及 Wi-Fi／移動資料 |
| 當前配置 | 節點名稱、訂閱更新時間，不記錄金鑰 |
| 具體場景 | 應用名稱、操作步驟與觀察到的結果 |
| 發生時間 | 註明日期、時間及所在時區 |

## 一翻雲常見問題

### 一翻雲登入成功後還需要做什麼？

確認訂閱狀態，按系統教程配置客戶端，再檢查目標應用的實際訪問。

### 客戶端匯入欄應該填寫哪個地址？

只填寫賬戶提供的對應格式訂閱；本頁四個連結用於訪問網站，不是個人訂閱。

### 當前套餐價格與活動在哪裡確認？

進入賬戶檢視當前訂單，核對實付金額、付款週期、流量重置、有效期、裝置限制與售後條件。歷史截圖和舊優惠碼不能代替當前交易條款。
