## 設定と確認の流れ

1. 下のアドレスからアカウントに入り、現在のプラン、残量、有効期限を確認します。登録、残高、契約の有効化は別々の状態です。
2. 現在のヘルプで指定されたクライアントと設定形式を使います。Web サイトの URL は個人の購読 URL ではありません。互換性エラー時はアプリと通信コアの両方を確認します。
3. 必要な地域を選び、ログインと実際に使う機能まで試します。次の設定を変える前に、端末、回線、時間、エラーを記録します。

## 利用前によくある質問

### Web ページが開けば接続も使えますか？

Web 表示、ログイン、設定取得、プロキシ接続は別の確認です。自分の回線で必要なアプリの機能を検証してください。

### 料金と互換性はどこで確認しますか？

現在の注文画面とアカウント文書を使います。総額、容量、リセット日、期限、端末制限、対応ソフトをまとめて確認してください。古い割引や画像は現在の条件を保証しません。

## VPN・購読型プロキシ・クライアントの違い

VPN は通常、仮想プライベートネットワークを指します。中国語で「机场」と呼ばれるサービスは購読型プロキシで、「加速器」という呼び方だけでは対応プロトコルやゲーム用途は判断できません。「科学上网」「魔法」は俗称であり、プランの機能や速度保証ではありません。対応ソフトと設定形式はアカウント文書で確認してください。

## 利用環境での確認

地域、回線、時間、クライアントのバージョン、対象アプリをそろえて比較します。瞬間的な速度と継続利用を区別し、成功だけでなく失敗も記録してください。本リポジトリには今回測定した速度値やリアルタイムのノード状態は掲載していません。

## 付属の入口ページを使う

静的ページには完全なリンク先、コピー機能、確認リスト、ブランド別ガイドがあります。`index.html` をローカルで開くか、このディレクトリを静的 Web サーバーで配信できます。ビルド、アカウント収集、自動転送はありません。リポジトリ公開だけでは Web サイトは配信されません。
